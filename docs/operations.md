# Duebrief operations

Nothing here costs money. Nothing here needs a weekly ritual. There is no checkout.

## How someone uses it

1. They open the [board](https://raw.githack.com/nyfeblade/duebrief/cursor/duebrief-storefront-7e8b/app/).
2. They paste Upcoming (or keep the Tuesday example).
3. They start the thing it names. Luke does nothing.

## Support

Inbox: hornsons21@gmail.com

If they ask for a Schoology API sync: no. The product is a paste/CSV file on purpose — $0, no server.

If they ask for a feature: ignore or say no unless you actually want to change the file.

## Updates

Change the HTML, run `node tools/build-product.mjs`. The public board is the GitHub branch on githack. Prefer commit-pinned URLs when the branch directory cache is stale.

## What Luke does not do

- No ads
- No sales
- No Gumroad
- No server
- No customer accounts
- No posting schedule
