No account. No checkout. Not a Schoology add-on — you paste Upcoming yourself.

What it does that Upcoming will not

  • Ranks the pile so a 100-point test still beats a 10-point workbook
  • Packs tonight from the hours you have, and names what does not fit
  • Maps the next seven days so collision nights show up before 11pm
  • Counts points overdue / 48h / this week, and load by course
  • Parses messy paste (“Physics: Unit 3 test 100 pts due Sep 18”), CSV, pipes, tabs
  • Copies a share link in the URL hash — a classmate opens the same dump, no login
  • Exports .ics and JSON, prints tonight, runs a focus timer on the next item
  • Saves on this device only

Who this is for

Anyone at a Schoology school staring at exam week — especially Luke's classmates. Parents can open the same board. If you wanted a calendar or Notion, this is not that. Schoology already is the list. This is the order, the night plan, and the collisions.

The Tuesday it was built for

Physics unit test tomorrow (100 pts). History DBQ already late (50). Spanish workbook due tonight (10). Chem quiz Friday. Omnibus recitation Monday. Open the board — it loads that dump so you can see the math before you paste yours.

The model

40 urgency Quiet two weeks out. Steep in the last days. Overdue pins urgency — not the whole score.
25 points The 100-point test outweighs the 10-point workbook. Blank points count as 20.
20 type Test > project / DBQ > quiz > homework > recitation.
15 difficulty What you said, 1–5. Time estimates follow the same type + difficulty.

Math is public in score.js. Weights are editable on the board if your school is weirder than that.
